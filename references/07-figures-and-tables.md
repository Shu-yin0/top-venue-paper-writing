# Figures and tables

- Set order: teaser (the claim) -> framework figure (mechanism; each box maps to one method paragraph) -> main table -> analysis figure (each panel maps to one subsection) -> small tables (diagnosis, transfer, ablation). Self-test: Fig. 1 -> Fig. 2 -> Table 1 reproduces claim -> mechanism -> evidence.
- Figures: vector PDF; one palette for the whole paper with the proposed method always the most salient; grey-print distinguishable (marker shapes as backup); text size at least the venue's small-figure floor (about the caption size); no truncated axes that mislead; qualitative figures may keep a failure case.
- Tables: booktabs three-rule style, no vertical lines, no \hline; best bold, second underlined if used; relative-difference column; units in headers; table caption above, figure caption below; numbers produced by script or macros, never typed by hand.
- Captions: start with the claim sentence ("X does Y"), then one sentence per panel, then symbols/error bars/bold rules; present tense, no meta-talk, no new result that the text lacks; two to four sentences.
- After every figure change rerun the figure audits (alignment, text, collisions) and look at the rendered image.

## Patterns and templates
- Reading order of a skimmer: title -> Figure 1 -> framework figure -> main table; these four must carry the claim chain alone. Teaser forms: comparison (failure vs success side by side + one headline number), phenomenon (draw the title's tension; first choice for mechanism papers), preview (small pipeline thumbnail, only if the method itself is the selling point). It includes one claim sentence in the figure, over-annotate rather than under-annotate, check spelling inside figures.
- Framework figure: left-to-right data flow; every box maps to one method paragraph (an orphan box means a stacked component); frozen parts grey, trainable parts in the accent colour; supervision as dashed arrows in one colour; arrows carry verbs; at most three lines of text per box; vector format; the same tool and style throughout.
- Chart types: trends = line + interval band; trade-offs = scatter + Pareto front; ablation = bars with error bars ordered by claim; variation = box/violin/ECDF; qualitative = image grid with failure cases included. Write the takeaway before drawing; saturate the key line and fade the rest; label directly rather than via a legend; units on axes; white = zero for sequential data, diverging scale for signed data; mark untested extrapolation.
- Colour: categorical <= 8 colours (Okabe-Ito), beyond that use marker shapes or direct labels; sequential = viridis family; no jet/rainbow; one palette across the paper, ours fixed accent, baselines grey, ablation variants shades of one hue; check in greyscale.
- Caption four parts: title sentence stating what the figure shows and why it matters (about one line), one sentence per panel, definitions (symbols, error bars, bold rule), optional reading hint. Red lines: "Overview of our method" and "Accuracy on CIFAR-10" captions; new results that the text lacks.
- Anti-patterns: figure without a claim, density explosion (tiny text, thirty curves, double legends), teaser = pipeline screenshot, figure and text with different number conventions, deleting failure cases for looks.
